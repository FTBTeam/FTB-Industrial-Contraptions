# Industrial Contraptions

> ## ⚠️ Renamed from FTB Industrial Contraptions: mod ID is now `ic`
>
> As of **26.1.2.10** the mod ID changed from `ftbic` to `ic` and every block and
> item ID changed with it (`ftbic:copper_ingot` is now `ic:copper_ingot`).
>
> **Back up your world before updating.** Existing worlds are carried over by a
> registry alias layer, but this is the one update where a backup is worth the
> two minutes it takes.
>
> **Pack developers:** aliases cover registry lookups only. Recipes, tags, loot
> tables, quest files, KubeJS scripts, and anything under `data/ftbic/` must be
> updated to `ic:` by hand. See [CHANGELOG.md](CHANGELOG.md) for the full list.
