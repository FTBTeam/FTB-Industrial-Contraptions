# <Color id="gold">Machine Upgrades</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="overclocker_upgrade" scale="2" />

  Machines that support upgrades have 4 upgrade slots and accept **4 upgrades total**, combined across all slots and types. One slot may hold a stack of 4. Parallel Processing Upgrades have a separate limit of 3 per machine. Shift-click a stack into the machine UI, or sneak-right-click the machine while holding upgrades to install as many as it can accept, up to 4 at once. Extra upgrades stay in your hand or inventory.
</Column>
